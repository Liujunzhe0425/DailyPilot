# 小米 14 Pro / Android 16 首次设置

适用范围：小米 14 Pro、Android 16、安全更新 2026-04-01。不同 HyperOS 小版本的菜单文字可能略有差异；App 中每个权限行只在用户点击后打开对应系统页面，返回 App 后会在 `onResume()` 重新检测。

## 必须授权

1. **无障碍服务**：设置 → 更多设置 → 无障碍 → 已下载的应用 → 每日领航。仅用于读取可见控件和执行用户已启用的三个低频模块。
2. **显示在其他应用上层**：允许决策框、停止和暂停按钮显示。没有该权限仍不得在后台强行启动页面。
3. **闹钟和提醒 / 精确定时**：设置 → 应用特殊权限 → 闹钟和提醒 → 每日领航。未授权时自动计划保持阻塞，不降级为不精确任务；手动运行仍可用。
4. **通知**：用于运行进度、失败摘要和短暂停止提示。
5. **电池策略“不限制”**：应用信息 → 省电策略 → 不限制。
6. **自启动**：设置 → 应用设置 → 授权管理 → 自启动管理 → 每日领航。

## 推荐设置

- 将微信小程序“湖南大学微生活”和“提现笔笔省”添加到手机桌面并保留默认名称；手机桌面也需保留“闲鱼”图标。
- 保持微信和闲鱼已登录；App 不保存账号、密码、Token 或 Cookie。
- 在系统多任务界面划掉控制 App 不影响已登记的系统闹钟；系统“强行停止”会阻断所有后台组件，之后必须重新打开 App。
- 不授予联系人、短信、电话、麦克风、相机、定位、安装应用、全部文件或 Shizuku 权限。

## 权限健康含义

- **手动运行可用**：无障碍和悬浮窗均已开启。
- **自动运行可用**：上述六项均已完成。
- 小米自启动没有可靠的公开读取接口，因此由用户进入系统页面确认后在本机记录；不会上传。

## 排障

- 定时点没有提示：检查精确定时、自启动、电池“不限制”和顶层自动运行开关。
- 解锁后没有决策框：检查显示在其他应用上层权限，并确认本周期没有已经选择“稍后运行”或等待 15 秒自动关闭。
- 系统更新后状态异常：重新打开 App，逐项进入权限页面并返回刷新。
