# DailyPilot（每日领航）安装与使用

适配目标：小米 14 Pro、Android 16。仅供本人侧载。

版本：`0.3.4 (25)`

推荐从 GitHub Releases 下载 APK；也可以按项目根目录 README 的构建说明自行生成。

## 安装

1. 将 APK 传到手机，允许文件管理器“安装未知应用”，完成安装。
2. 打开“每日领航”，先不要开启总开关。
3. 在微信中把“湖南大学微生活”和“提现笔笔省”添加到手机桌面，保留默认快捷方式名称；手机桌面也需保留“闲鱼”图标，并确认微信、闲鱼已正常登录。
4. 在“设置与权限”中依次开启：无障碍、悬浮窗、精确定时、通知、电池不限制、小米自启动。
5. 回到 App，设置每日时间；在“模块开关与排序”中启停模块、拖动顺序；最后开启“每日自动运行”。

## 运行规则

- 到点若手机锁定，任务等待自然解锁，不保存或模拟锁屏密码。
- 解锁后每个周期只显示一次 15 秒“运行/稍后运行”悬浮框；超时等同“稍后运行”。
- 选择运行后，按当前顺序执行所有已启用模块；也可在 App 内运行全部或单独运行。
- 每个模块先检查今日状态。已完成直接跳过；未知状态不点击；页面最多等待 15 秒并重试一次。
- 红色悬浮按钮：先暂停，再确认是否停止本次运行；取消会继续。
- 蓝色按钮：运行时点击立即暂停；暂停时点击并确认后继续。暂停满 3 分钟会终止本批次。
- 文字记录保留 30 天；失败截图默认保留 7 天，可在设置关闭或手动清理。

## 严格安全边界

- 笔笔省只领取唯一、明确免费的提现券；面额动态识别，不参与购物、游戏、视频、支付等任务。
- 闲鱼只接受精确的普通“擦亮”入口；“超级擦亮”、推广、充值、支付、扣费或权益页面一律不操作。
- 验证码、人脸、设备安全验证或登录失效时，不输入凭据、不绕过验证，只记录为需要人工处理并继续其他模块。
- 软件不抓包，不保存微信/闲鱼 Token、Cookie 或密码，不调用未公开接口，不使用 Root/Shizuku。

## 小米后台设置建议

- 系统设置 → 应用 → 每日领航 → 电量消耗 → 无限制。
- 手机管家 → 应用管理 → 权限 → 自启动管理 → 允许。
- 最近任务中划掉控制 App 不应取消 AlarmManager 定时；但系统“强行停止”后必须重新打开 App 并重新开启总开关。

## 首次真机校准与故障处理

微信小程序和闲鱼页面会随版本变化。首次使用先点“只检查今日状态”，确认日志能识别当前状态，再进行单模块运行。若显示“状态未知/找不到明确免费入口”，不要反复尝试；保留失败记录，并用项目提供的只读 UI 采集脚本更新选择器。
