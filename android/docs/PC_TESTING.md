# 在电脑上测试 DailyPilot（每日领航）

## 可以完整在电脑验证的部分

- 原生首页、模块管理、排序、设置和历史界面；
- Room 数据库、日志与截图保留策略；
- 定时周期、锁屏状态机、15 秒决策逻辑；
- 前台服务、通知、红蓝悬浮按钮、暂停/停止和 3 分钟超时；
- 权限缺失分支、进程恢复、安全文本边界和 APK 安装启动。

直接执行：

```powershell
.\tools\pc-emulator-test.ps1
```

若模拟器尚未启动，脚本会自动打开 Android 16 AVD；随后自动构建、安装、先禁止悬浮窗权限复测崩溃路径、再授权并运行全部设备测试，最后冷启动首页并扫描崩溃日志。使用 `-NoWindow` 可改为无界面后台运行。

## 不能由普通电脑模拟器证明的部分

微信和闲鱼登录、风控、小程序 WebView 节点、小米 HyperOS 后台限制，以及“免费擦亮”的真实入口，都依赖目标手机、账号和当前线上页面。合成 fixture 只能验证“不误点”，不能证明线上选择器一定命中。

## 最省事的真实验收方式

手机只需首次开启 USB 调试并授权电脑。之后用：

```powershell
.\tools\deploy-to-phone.ps1 -Serial <adb序列号>
```

它使用同签名 `adb install -r` 覆盖安装，保留数据库和绝大多数授权，不需要反复把 APK 传到手机或手动安装。电脑安装 `scrcpy` 后，脚本还会自动在电脑窗口中镜像并控制手机；这样可以在电脑操作，但运行环境仍是真实的小米 14 Pro。
